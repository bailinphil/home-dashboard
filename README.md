# Overview

This project is a dashboard meant to show my family information about the day's events on an e-ink tablet mounted on the wall. I am beginning this project as a way to continue learning to work with AI tools in a no-stakes setting.

## Main Features

1. Display the day's schedule, according to a combination of our family's Google calendars
2. Display the [picture of the day](http://bailinphil.com/backlog) on my personal website
3. Display the current actions that my young children should be performing, helping them to know:
   1. What kind of clothes to wear today (for the weather)
   2. What activity is current (play, dinner, get ready to go to school, etc.)
   3. How many minutes until the next step (showing what the analog clock above will look like when it's time to change)
4. Display recent air quality readings from my [sensors in the kitchen](https://github.com/bailinphil/kitchen-lights)
